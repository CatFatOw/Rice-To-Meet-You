# Michael's Branch

This is **Michael's branch** for brainstorming, prototypes, notes, AI-assisted experiments, and work-in-progress ideas.

The `main` branch is the production branch. Only merge this branch into `main` after the group reviews and approves the work.

## Git Steps

### 1. Clone the project

```bash
git clone https://github.com/CatFatOw/Rice-To-Meet-You.git
cd Rice-To-Meet-You
```

### 2. Switch to this branch

```bash
git checkout michael-brach
```

### 3. Get the latest changes

```bash
git pull
```

### 4. Check your changes

```bash
git status
```

### 5. Add your files

```bash
git add .
```

### 6. Commit your work

```bash
git commit -m "Describe your change"
```

### 7. Push your branch

```bash
git push
```

## Pull Request Steps

When the branch is ready for review:

1. Go to `https://github.com/CatFatOw/Rice-To-Meet-You`.
2. Click **Pull requests**.
3. Click **New pull request**.
4. Set **base** to `main`.
5. Set **compare** to `michael-brach`.
6. Write a clear title and short description.
7. Ask the group to review it.
8. Merge only after approval.
